## 🎯 About the Project

The **Pixel Portfolio Website** is my personal portfolio, designed to combine modern web development with nostalgic, game-inspired visuals.

It presents my technical journey, projects, skills, education, internship experience, certifications, and contact information through a distinctive retro interface.

The website focuses on interactive elements, clean navigation, responsive design, and subtle animations to create an engaging experience for recruiters, developers, and visitors.

## ✨ Features

- 🎨 Retro pixel-art-inspired UI
- 🌙 Light and dark modes
- 🖱️ Custom pixel cursor
- ⚡ Animated loading screen
- ⌨️ Typing text animations
- 📜 Smooth-scrolling navigation
- 🎮 Playable Crab Runner mini-game
- 📱 Responsive layout for different screen sizes
- 💼 Interactive project showcase
- 🧠 Skills organized by technical domain
- 🎓 Education and certifications sections
- 👨‍💻 Internship experience showcase
- 📞 Contact section
- ✨ Animated backgrounds and visual effects

## 🛠️ Technologies Used

**Frontend**
- HTML5
- CSS3
- Vanilla JavaScript

**Styling and Layout**
- CSS Variables
- Flexbox
- CSS Grid
- Responsive Design
- Media Queries
- CSS Animations and Transitions

**Graphics and Interactivity**
- HTML5 Canvas
- Custom Pixel Art
- Custom Cursor Effects
- Particle Effects
- Typing Animations
- Intersection Observer API
